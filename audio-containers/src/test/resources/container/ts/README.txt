Synthetic TS/PES boundaries built directly from ISO MPEG-TS structures: PAT/PMT with MPEG-2 CRC32, bounded 188-byte packets, explicit continuity counters and PES headers. No recordings or user data. pat-pmt-update switches both PMT and elementary PID; split-psi crosses a TS packet; pes-40000 uses unsigned PES_packet_length=40000. The remaining files each deliberately corrupt the named structure (duplicate packet content, continuity, truncation, header size, PTS marker, PSI CRC or adaptation size). Expected plaintext is constant byte 0x55; no FFmpeg is required to run tests.
pmt-15-first/pmt-17-first contain the same ADTS elementary PID and a LATM track, listed in either PMT order; selection must retain supported ADTS in both cases.
