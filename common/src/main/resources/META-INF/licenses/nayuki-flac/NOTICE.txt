MusicHud-TuneWeave modifications, 2026-09-10:
- Relocated six supporting decoder/header/bit-stream source files into the fork namespace.
- Added 33-bit signed subframe reads and corrected the 33-bit LPC bound literal.
- Recognized RFC 9639's 32-bit frame depth code and corrected kHz sample-rate decoding.
- Rejected exhausted wasted-bit depths and noncanonical UTF-8 coded frame numbers.
- Streaming adapter, byte budgets, metadata validation and lifecycle are implemented by the fork outside these source files.
